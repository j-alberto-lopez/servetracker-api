Backend REST desarrollado con Spring Boot orientado al análisis de beneficios y control de stock en entornos TPV.

## Descripción

Servetracker es una API diseñada para gestionar productos, stock y ventas, permitiendo analizar la rentabilidad del negocio mediante alertas y control de consumos.

## Funcionalidades

- Gestión de productos (CRUD)
- Control de stock
- Sistema de tickets (ventas)
- Consumo de stock automático
- Base para sistema de alertas de rentabilidad

## Tecnologías

- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL

## Enfoque del proyecto

Este proyecto está orientado a simular un entorno real de negocio, donde no solo se gestionan ventas, sino que se analizan beneficios y consumos para la toma de decisiones.

## Arquitectura

El proyecto está diseñado como una API backend independiente que será consumida por un frontend desarrollado en Angular.
